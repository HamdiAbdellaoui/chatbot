# Human Evaluation Rubric (Blind Review)

Use this rubric to score `answer_a` vs `answer_b` for the same question.

## Winner
- `a`: Answer A is better overall
- `b`: Answer B is better overall
- `tie`: Roughly equal

## 1–5 Scores (per answer)
Score each dimension from **1 (bad)** to **5 (excellent)**.

### Helpfulness
- 1: Does not answer, irrelevant, or unhelpful
- 3: Partially answers, missing key details
- 5: Fully answers, addresses user intent, actionable

### Groundedness / Truthfulness
- 1: Makes up facts, hallucinates, or contradicts known policy
- 3: Some uncertainty / mild speculation
- 5: Sticks to known info, clearly states uncertainty when needed

### Clarity
- 1: Hard to understand, messy, wrong language/register
- 3: Understandable but verbose/unclear in parts
- 5: Clear, concise, correct language mirroring

## Notes
Write brief notes when:
- The answer contains potential hallucinations
- The answer violates policy/safety expectations
- The answer fails language mirroring
- The answer should have escalated or asked a clarifying question
